# Reporting a security problem

If you find a security problem in kits.teleagriculture.org or any TeleAgriCulture code,
please tell us privately rather than opening a public issue or post.

Email **[letmegrow@teleagriculture.org](mailto:letmegrow@teleagriculture.org)** with:

- what you found, and where (a page, an address or a file);
- how to reproduce it;
- what someone could do with it.

Please don't access other people's data, change anything, or disrupt the site while
checking. We'll reply to say we've received your report, and let you know when it's fixed.

This is a small project with no bug bounty, but we're grateful for every
report and happy to credit you if you'd like.
