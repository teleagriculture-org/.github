# TeleAgriCulture

A cloud/crowd agricultural data network for artists, growers and researchers. People build
open-hardware sensor kits, put them in gardens, greenhouses, rivers and fields, and share
what they measure.

## Where to go

| | |
|---|---|
| **[teleagriculture.org](https://teleagriculture.org)** | The project: what it is, who is behind it, workshops and events |
| **[kits.teleagriculture.org](https://kits.teleagriculture.org)** | Live readings from kits around the world, the projects behind them, and kits to order |
| **[Guides](https://kits.teleagriculture.org/guides)** | Setting up a board, calibrating sensors, working on the firmware |
| **[TeleAgriCulture/main](https://github.com/TeleAgriCulture/main)** | The board's open-source firmware and hardware documentation |

## Using the data

Readings from every published kit can be downloaded through a public API, with no account
needed. See [Get your data with the API](https://kits.teleagriculture.org/guides/api).
